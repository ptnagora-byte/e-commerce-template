# E-commerce Template

Crie um PROJETO NOVO e independente chamado 'E-commerce Template' na minha workspace. OBJETIVO: apenas preparar uma estrutura técnica mínima para receber pelo GitHub o código de uma loja virtual que JÁ ESTÁ PRONTO fora do Lovable. Não reconstrua a loja, não invente produtos, textos ou preços, não configure banco de dados, não instale dependências extras, não conecte pagamentos e não modifique nenhum projeto existente. Basta um scaffold padrão com página temporária simples intitulada 'E-commerce Template'. Posteriormente vincularei este projeto a um repositório NOVO via Git Sync e enviarei o código pronto diretamente pelo GitHub. Lovable será usado para prévia e publicação; nenhuma futura alteração de código deverá ser feita por seu editor de IA.
